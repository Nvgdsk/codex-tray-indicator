# Contributor Covenant Code of Conduct

## Commitment and standards

This project adopts [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in full by reference. Please read the complete covenant linked above.

Everyone should be able to participate without harassment or discrimination.
Be kind, respect different experiences, accept constructive feedback, and take
responsibility for mistakes. Sexual harassment, personal attacks, intimidation,
disclosing another person's private information, and repeated disruptive conduct
are unacceptable.

## Scope and responsibility

The covenant applies in project spaces and when representing the project publicly.
The repository owner and appointed maintainers enforce it fairly, may moderate
contributions, and protect reporters' privacy.

## Reporting and enforcement

Contact the repository owner through the contact methods on their public GitHub
profile. If no private channel is listed, use the project's
[private advisory reporting route](../../security/advisories/new) and identify the
report as a code-of-conduct matter. If unavailable, ask for a private contact without
posting incident details. This route is also described in [SECURITY.md](SECURITY.md).

Enforcement follows the covenant's four levels: correction, warning, temporary ban,
and permanent ban, proportionate to impact and repeated behavior.
